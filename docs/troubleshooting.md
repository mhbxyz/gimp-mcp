# Troubleshooting

<!-- Generated from src/gimp_mcp/doctor.py (CHECKS) by `gimp-mcp doctor --troubleshooting`. -->

Run `gimp-mcp doctor` first: it runs the checks below in order and prints, for each failure or
warning, what it found and how to fix it. `gimp-mcp doctor --json` gives the same result for scripts.

Exit codes: `0` no failure (warnings allowed), `1` at least one failure, `2` the doctor could not run.

| Check | What it verifies | Fix when it fails |
|---|---|---|
| `gimp` | GIMP 3.2 or newer is installed | **Linux:** Install GIMP 3.2 or newer from your distribution (e.g. `sudo pacman -S gimp`) or Flathub (`flatpak install flathub org.gimp.GIMP`); gimp-mcp needs `gimp-console` on PATH or GIMP_MCP_GIMP_CONSOLE pointing to it.<br>**macOS:** Install GIMP 3.2 or newer from gimp.org and drag it to Applications (gimp-mcp looks for /Applications/GIMP.app and ~/Applications/GIMP.app); elsewhere, set GIMP_MCP_GIMP_CONSOLE to GIMP.app/Contents/MacOS/gimp-console-3.2.<br>**Windows:** Install GIMP 3.2 or newer with the installer from gimp.org (gimp-mcp looks in `%ProgramFiles%\GIMP 3` and `%LOCALAPPDATA%\Programs\GIMP 3`); elsewhere, set GIMP_MCP_GIMP_CONSOLE to its `bin\gimp-console-3.2.exe`. |
| `gimp-python` | GIMP's Python can load PyGObject and the GIMP typelib | **Linux:** Install PyGObject for the system Python and GIMP's introspection data (Arch: `python-gobject`; Debian/Ubuntu: `python3-gi gir1.2-gimp-3.0`; Fedora: `python3-gobject`).<br>**macOS:** Reinstall GIMP 3.2 from gimp.org: GIMP runs plug-ins with the Python inside GIMP.app, which must import `gi`.<br>**Windows:** Reinstall GIMP 3.2 from gimp.org: GIMP runs plug-ins with the Python of its own installation (`bin\python.exe`), which must import `gi`. |
| `venv-path` | No virtualenv shadows the Python GIMP runs plug-ins with | **Linux:** Start GIMP from your desktop or from a shell without the virtualenv (`deactivate`): GIMP runs Python plug-ins with the first `python3` on PATH.<br>**macOS:** Nothing to do: GIMP runs plug-ins with the Python inside GIMP.app, whatever PATH says.<br>**Windows:** Nothing to do: GIMP runs plug-ins with the Python of its own installation, whatever PATH says. |
| `profiles` | The plug-in is installed in the GIMP profile actually used | **Linux:** Run `gimp-mcp install-plugin --gimp-dir <profile used by GIMP>` (default ~/.config/GIMP/3.2, or $GIMP3_DIRECTORY).<br>**macOS:** Run `gimp-mcp install-plugin --gimp-dir <profile used by GIMP>` (default ~/Library/Application Support/GIMP/3.2, or $GIMP3_DIRECTORY).<br>**Windows:** Run `gimp-mcp install-plugin --gimp-dir <profile used by GIMP>` (default `%APPDATA%\GIMP\3.2`, or `%GIMP3_DIRECTORY%`). |
| `plugin` | The bridge plug-in is installed and executable | Run `gimp-mcp install-plugin`, then restart GIMP. |
| `plugin-version` | The installed plug-in has the server's version (another version works when it speaks the same bridge protocol; tools it cannot serve ask for an update) | Run `gimp-mcp install-plugin` with the gimp-mcp you use as MCP server, then restart GIMP. |
| `plugin-registered` | GIMP has registered the plug-in | Restart GIMP. If the plug-in is still not registered, GIMP could not run it: see the gimp-python and venv-path checks, and GIMP's error console. |
| `socket-permissions` | The bridge socket directory and token are private | **Linux:** Restart GIMP to recreate them, or fix them: `chmod 700 <socket dir>` and `chmod 600 <token file>` (they must belong to you).<br>**macOS:** Restart GIMP to recreate them, or fix them: `chmod 700 <socket dir>` and `chmod 600 <token file>` (they must belong to you).<br>**Windows:** Nothing to fix by hand: the bridge's named pipe admits only your user (its ACL is set when GIMP starts). Restart GIMP if the connection check fails. |
| `connection` | A running GIMP answers on the bridge | Start GIMP (after `gimp-mcp install-plugin`). If GIMP is already running, restart it so it loads the plug-in. |
| `instances` | Only one GIMP instance competes for the bridge | **Linux:** Close the extra GIMP instances, or give each one its own socket with GIMP_MCP_SOCKET (set it for GIMP and for `gimp-mcp serve`).<br>**macOS:** Close the extra GIMP instances, or give each one its own socket with GIMP_MCP_SOCKET (set it for GIMP and for `gimp-mcp serve`).<br>**Windows:** Close the extra GIMP instances, or give each one its own pipe with GIMP_MCP_SOCKET (`\\.\pipe\<name>`, set for GIMP and for `gimp-mcp serve`). |
